# 腹筋トレーニング記録

腹筋・体幹トレーニングの日々の記録をつけ、体重や見た目の変化が「トレーニングの影響かどうか」を切り分けるための、小さな静的ウェブサイトです。

7種類の腹筋動画（動画A〜G）を毎回変えながらローテーションして行う週4回程度のルーティーンを想定していますが、軽い体幹の日や休みの日も含めて記録できます。

## 使い方

1. `index.html` をブラウザで開きます（ファイルを直接開いても、静的ホスティングに置いても使えます）。
2. 日付、セッションの種類（動画A〜G／軽い体幹／なし）、実施したかどうか、翌日の筋肉痛（0〜3）、腰の違和感（0〜3）を入力します。
3. 任意で体重、睡眠時間、外食の有無、長く歩いたかどうか、メモも記録できます。
4. 「保存する」を押すと、その日の記録が一覧に追加されます。一覧から編集・削除もできます。
5. グラフで体重の推移（トレーニング実施日はマーカーが大きくなります）、週ごとのセッション数（週4回の目標ライン付き）、動画別の実施回数を確認できます。各グラフには「このグラフの見方」の説明が付いています。
6. 「切り分けメモ（集計）」では、総セッション数、直近28日のセッション数、体重の変化、そして週4回以上トレーニングした週とそれ未満の週の平均体重を比べられます。

ビルドは不要です。グラフの描画には Chart.js を CDN から読み込んでいます。

## プライベート同期（任意）

記録を非公開リポジトリにも自動送信して、別の端末や集計ツールから読み取れるようにする仕組みです。

1. GitHub にデータ専用の **Private** リポジトリ（例: `abs-training-data`）を作り、空の `data.json`（中身は `[]`）を置きます。
2. GitHub の Settings → Developer settings → Personal access tokens → Fine-grained tokens で、そのリポジトリ **だけ** を対象に、Contents の Read and write 権限を持つトークンを発行します。
3. サイトの「プライベート同期」で、リポジトリ名（owner/repo）とトークンを入力し、「設定を保存して同期」を押します。
4. 以降、記録を保存・編集・削除すると `data.json` へ自動で送信されます。別の端末では、同じ設定を入れると記録を読み込めます（端末に記録がない場合は自動で取り込みます）。

注意:

- トークンは各ブラウザの localStorage にだけ保存されます。コードやリポジトリに書き込まないでください。他人にも共有しないでください。
- 同期先は必ず **Private** リポジトリにしてください。体重などの記録が入るため、Public リポジトリには送信しないでください。

## 取り入れている技術

- **PWA**: `manifest.webmanifest` と Service Worker（`sw.js`）により、ホーム画面への追加（インストール）とオフライン表示に対応しています。ページ本体はネットワーク優先で取得するため、サイトの更新はそのまま反映されます。
- **タブ切り替え**: データの入出力とプライベート同期は JavaScript のタブで表示を切り替えています。
- **Chart.js**: 体重推移、週ごとのセッション数（目標ライン付き）、動画別の実施回数をグラフ化しています。
- **localStorage**: 記録データの保存先です。サーバー送信はしません。
- **dialog要素 + 埋め込みプレイヤー**: 動画再生にモーダルダイアログを使っています。
- **Web Share API**: 「このサイトを共有」ボタンから共有でき、未対応のブラウザではURLコピーに切り替わります。
- **キーボードショートカット**: フォーム入力中に Ctrl+Enter（Macは Cmd+Enter）で保存できます。

## デザインとレイアウト

- 2026-11-07にClaudeが全面リデザインした、ホームページ型の構成です。ヘッダーのナビ、ヒーロー（概要＋総セッション数などの集計3点）、動画ライブラリ（7本のカード形式で、対象部位／強度★／特徴／こんな日・注意点を表示）、ローテーションの仕組み、記録フォーム、グラフと集計、記録一覧、データと同期、の順に通常スクロールで読み進めます。
- デザインはデジタル庁デザインシステム（DADS）を参考にした基調色の青（#0017c1）で、キーボード操作時のフォーカス表示（黒い輪郭＋黄色のリング）などを取り入れています。
- コードはインラインCSS／JavaScriptを使わない外部ファイル構成で、BEM命名・セマンティックHTML・WCAG 2.2 AAに沿っています。記録データの保存形式・localStorageキー・同期仕様は旧版と完全互換です。

## データとプライバシー

- **記録データは、開いているブラウザの localStorage にだけ保存されます。** サーバーへ送信されることはありません。
- このリポジトリのファイルには個人情報は含まれていません。実データはコードやリポジトリに書き込まれず、各端末のブラウザの中にのみ存在します。
- そのため、**エクスポートした JSON ファイルはリポジトリにコミットしないでください。** バックアップは手元の安全な場所に置いてください。
- ブラウザのデータを消去すると記録も消えます。ときどき「JSONを書き出す」でバックアップを取ることをおすすめします。
- メモ欄に個人情報（名前・住所・学校名・場所など）を書かないでください。スクリーンショットを共有すると、その内容が見えてしまいます。

## バックアップと復元

- 書き出し：画面の「JSONを書き出す」ボタンで、全記録を JSON ファイルとして保存できます。
- 読み込み：画面の「JSONを読み込む」ボタンで、書き出した JSON から復元できます（現在のデータは置き換わります）。

## GitHub Pages で公開する手順（一般的な流れ）

1. このフォルダの中身（`index.html` など）を GitHub のリポジトリに置きます。実データの JSON は含めないでください。
2. リポジトリの Settings を開き、Pages の項目を選びます。
3. 公開ソースとして、対象ブランチ（例：main）とルートフォルダ（/ (root)）を選び、保存します。
4. しばらくすると公開用 URL が表示され、その URL からサイトを開けるようになります。
5. 公開しても、見る人のブラウザにはその人自身の localStorage の記録だけが表示されます。あなたの記録が公開されることはありません。

## ファイル構成

- `index.html` — ページ本体（HTMLのみ。CSS/JSは外部ファイル）
- `css/tokens.css` — デザイントークン（色・余白・文字）
- `css/base.css` — リセットとベーススタイル
- `css/style.css` — メインスタイル（tokens と base を `@import` で束ねる）
- `js/main.js` — 記録・集計・グラフ・同期の全ロジック
- `manifest.webmanifest` — PWA用マニフェスト
- `sw.js` — Service Worker（オフライン対応）
- `icon.svg` — アイコン
- `README.md` — このファイル
